# واکی‌تاکی عقیل | Aghil Walkie-Talkie

پروژهٔ اولیهٔ قابل توسعهٔ واکی‌تاکی اینترنتی با رابط فارسی، کانال، نام کاربر، دکمهٔ نگه‌داشتن برای صحبت (Push-to-Talk)، WebRTC برای صدای زنده و WebSocket برای هماهنگی اتصال‌ها.

## ساختار
- `index.html`: رابط کاربری واکنش‌گرا
- `server.js`: سرور سیگنالینگ WebSocket
- `package.json`: فرمان‌های اجرا و وابستگی‌ها
- `capacitor.config.json`: تنظیمات بسته‌بندی اندروید
- `.github/workflows/android.yml`: ساخت APK آزمایشی با GitHub Actions

## اجرای سرور
نیازمند Node.js 20 یا جدیدتر:
```bash
npm install
npm start
```
سرور به‌صورت پیش‌فرض روی پورت 8080 اجرا می‌شود. متغیر محیطی `PORT` قابل تنظیم است.

## اجرای رابط وب
```bash
npm run dev
```
در برنامه، نشانی WebSocket سرور را وارد کنید، مثلاً `ws://localhost:8080`. برای استفاده از اینترنت و گوشی، سرور باید روی یک میزبان عمومی با HTTPS/WSS مستقر شود؛ آدرس عمومی را در تنظیمات وارد کنید.

## ساخت APK
Workflow بخش Actions پس از اجرا، APK آزمایشی را به‌صورت artifact منتشر می‌کند. همچنین می‌توان با Android SDK نصب‌شده اجرا کرد:
```bash
npm install
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```
خروجی: `android/app/build/outputs/apk/debug/app-debug.apk`

## نکات مهم
- این پروژه از WebRTC استفاده می‌کند. برای اتصال پایدار میان شبکه‌های مختلف، معمولاً به سرور STUN و گاهی TURN نیاز است؛ تنظیم TURN در این نسخه هنوز انجام نشده است.
- سرور فعلی فقط پیام‌های سیگنالینگ و وضعیت اتاق را رله می‌کند و صدای کاربران را ذخیره نمی‌کند.
- این نسخه برای آزمایش و توسعه است، نه سامانهٔ عملیاتی نیروهای امدادی/پلیسی. پیش از استفادهٔ واقعی باید احراز هویت، کنترل دسترسی، TLS، TURN، محدودسازی نرخ و آزمون امنیتی اضافه شود.
- مجوز میکروفون باید هنگام اولین استفاده تأیید شود. در وب، میکروفون فقط در localhost یا زمینهٔ HTTPS مجاز است.
