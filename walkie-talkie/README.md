# واکی‌تاکی عقیل | Aghil Walkie-Talkie

نسخهٔ اولیهٔ قابل اجرا از واکی‌تاکی اینترنتی با رابط فارسی، کانال‌های گروهی، دکمهٔ نگه‌داشتن برای صحبت (Push-to-Talk)، صدای زندهٔ WebRTC و سرور سیگنالینگ WebSocket.

## اجرا روی سرور
نیازمند Node.js 20 یا جدیدتر:
```bash
cd walkie-talkie
npm install
npm run start
```
برنامه روی پورت `8080` اجرا می‌شود (یا مقدار متغیر محیطی `PORT`). مسیر سلامت: `/healthz`. برای اتصال کاربران از طریق اینترنت، سرور باید پشت HTTPS/WSS در یک میزبان عمومی اجرا شود.

## توسعهٔ محلی
در یک ترمینال:
```bash
cd walkie-talkie
npm install
npm run build
npm run server
```
برای رابط توسعه، ترمینال دوم باز کنید و اجرا کنید:
```bash
cd walkie-talkie
npm run dev
```
در رابط برنامه، آدرس WebSocket را با مسیر `/signal` وارد کنید، مانند `ws://localhost:8080/signal`. در محیط عمومی از `wss://` استفاده کنید.

## ساخت APK اندروید
Workflow با نام **Build Walkie-Talkie Android APK** در بخش Actions مخزن اجرا می‌شود. بعد از پایان موفقیت‌آمیز، artifact با نام `aghil-walkie-talkie-debug-apk` قابل دریافت است. فایل APK آزمایشی است و هنوز با کلید انتشار امضا نشده است.

## امکانات فعلی
- رابط فارسی و واکنش‌گرا
- نام کاربر و کانال مشترک
- میکروفون با نگه‌داشتن دکمه و قطع هنگام رها کردن
- صدای مستقیم بین مرورگرها با WebRTC
- رلهٔ پیام‌های اتصال از طریق WebSocket
- محدودیت پایه برای اندازهٔ پیام و تعداد اعضای کانال

## محدودیت‌ها و امنیت
این نسخه نمونهٔ توسعه است، نه سامانهٔ عملیاتی پلیس یا امداد. سرور فعلی احراز هویت ندارد؛ هر فردی که آدرس سرور و نام کانال را بداند ممکن است وارد شود. برای استفادهٔ واقعی باید احراز هویت و مجوز کانال، TLS، محدودسازی نرخ، ثبت رویدادهای امنیتی، TURN برای شبکه‌های سخت‌گیر و آزمون امنیتی اضافه شود. صدای WebRTC از طریق سرور عبور نمی‌کند و در سرور ذخیره نمی‌شود؛ اما کیفیت اتصال به NAT و تنظیمات شبکه وابسته است.

مجوز میکروفون باید هنگام اولین استفاده تأیید شود. مرورگر برای دسترسی میکروفون به HTTPS یا localhost نیاز دارد.
